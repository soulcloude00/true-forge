## Round 1 gaps

1. Three independent reads forced the agent to reconcile related evidence itself.
2. No MCP output schemas or structured content were advertised, prompting tool-shape discovery.
3. Cost comparisons were left to the model rather than computed deterministically.
4. The Nimbus AWS credential context did not match the earlier AWS Core inventory. This is a release-blocking evidence-integrity issue for claims about the user's connected account.
